MWS官网现已重构。

2026-10-03 21:31:29MogroWang本文无任何 AIGC

MWS × Plainstruct

我终于放弃了断更的开源版 Gridea，转向了由 MogroWang Studio 自行 Vibe Coding 开发的 Plainstruct（素构）。

为什么想换软件？

理由很简单，旧版的 Gridea： （ https://github.com/getgridea/gridea ）
虽然算得上是轻量化博客的开山鼻祖，但是很多功能实际上算不上好用，尤其是 Markdown 编辑器，性能比较拉跨，个性化程度也不够，软件架构也有些过时。开源版的 Gridea 也失去了原作者的维护。

后来，AI发展起来了。我又在 GitHub 上发现，有人捣鼓出了 Gridea Pro。
（ https://github.com/Gridea-Pro/gridea-pro ）

我很开心能看到一个开源项目死灰复燃，但是事实上 Gridea Pro 反而不太稳定。所以我继续用着 Gridea。

我一直在找一个符合我胃口的静态博客创建软件，而且要够轻量，够好用，就像写 Word 文档那样。

时间的齿轮开始转动

下一步，我开始探索 Vibe Coding，下载了 Codex，开始了探索。起手就是用 GPT 5.6 Sol 写了一个特别简陋的待办软件。
我被惊喜到了。因为这意味着我真的可以说几句话，就做出一款软件。
我开始构想……为什么不做一款待办和笔记融合在一起的软件呢？
Acta（行记）应然而生，这一是我的第一款以 Vibe Coding 方式开发的软件。
（Acta 介绍页： https://acta.mogrowangstudio.top/ ）
（Acta GitHub 仓库 https://github.com/MogroWangStudio/Acta ）

关于 Vibe Coding 的故事不展开过多了。
为什么提及 Acta 呢，因为 Acta 成功让我开启了潘多拉魔盒，跑通了设计 + Vibe Coding 的流程，这让我开始着想于下一款软件。
正好 Acta 缺文档介绍页，那我就想做一个静态文档创建器。
这便是 Plainstruct（素构）的由来。
（Plainstruct 介绍页： https://plainstruct.mogrowangstudio.top/ ）
（Plainstruct GitHub 仓库： https://github.com/MogroWangStudio/Plainstruct ）

转型

其实在 Plainstruct 设计之初，没有考虑到博客站点，我只是想做一个文档站点创建器。
后来，我发现，文档站点的文件树，还有静态站点的一键发布流程等，完全可以应用于博客站点。
这让我不禁想起了断更半年的 MWS 博客官网。
于是，说干就干，让 Zcode 用 GLM 5.3 Flash 模型直接为 Plainstruct 加上了博客站点的功能和主题，而且站点可以无损在博客站点和文档站点间来回切换。

重心转移

于是我将 Plainstruct 的开发重心偏移向了博客站点，为了主要就是重构 MWS 博客官网。
一天天，一句句话，几十个commit……
如今终于在我心中达到了一个及格线，能够投入使用。
当然，这并不意味着 Plainstruct 会抛弃文档站点的更新。我相信不久后 Plainstruct 也将拥有自己的文档站点。

慢慢来。

慢慢来，慢慢来。
重构只是第一步，激活创作热情才是目的。
后续也将慢慢转移旧版本网站上的文章。
对了，我也更新了 MogroWang Studio 的新slogan：

Endless exploration. Ardent creation.

希望工作室能在之后更新的更频繁，创作更多内容~
敬请期待罢。

感谢你的阅读。
